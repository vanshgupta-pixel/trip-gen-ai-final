# TripGenie AI — React starter website

A responsive travel-planning frontend built with React, Vite, Lucide icons, and custom CSS.

## Run locally

Install Node.js LTS and Python, then install the backend dependencies:

```bash
pip install -r backend/requirements.txt
```

Start the API in one terminal:

```bash
python -m uvicorn main:app --reload --app-dir backend
```

Start the frontend in another terminal:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173/). The planner sends requests to the API at http://localhost:8000. Set `VITE_API_URL` if the backend is hosted elsewhere.

## Included

- Responsive landing page and navigation
- Destination, date, traveller, budget and interest form
- API-generated starter itinerary based on selected trip preferences
- Destination cards and save/remove trip interactions
- Mobile responsive layout

## Important notes

The backend returns a starter itinerary; it is not generated by an LLM and does not include live travel data. Saved trips exist only in page memory and disappear when the page is refreshed. Login, database persistence, live maps/prices, hotel availability and actual booking are not connected.

## Suggested next steps

1. Connect an LLM provider to the trip-planning endpoint.
2. Add an LLM API key in a backend environment variable (never put secrets in React frontend code).
3. Implement a `/api/plan-trip` endpoint and connect the form.
4. Add a database for user accounts and saved trips.
5. Add verified maps/places and booking provider integrations as needed.
